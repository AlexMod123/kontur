## Сборка

### Способ 1 — Python

```python
with open("kontur_v18_part1.py", encoding="utf-8") as f:
    p1 = f.read()
with open("kontur_v18_part2.py", encoding="utf-8") as f:
    p2 = f.read()
with open("kontur_v18.py", "w", encoding="utf-8") as f:
    f.write(p1 + "\n" + p2)
```

### Способ 2 — Командная строка (Linux/macOS)

```bash
cat kontur_v18_part1.py kontur_v18_part2.py > kontur_v18.py
```

### Способ 3 — Командная строка (Windows PowerShell)

```powershell
Get-Content kontur_v18_part1.py, kontur_v18_part2.py | Set-Content kontur_v18.py -Encoding UTF8
```

## CLI-команды

```bash
# Базовый расчёт
python kontur_v18.py --cli --template Офис --tier 1

# С экспортом всех форматов
python kontur_v18.py --cli --template ЦОД --tier 3 --export

# Сохранение проекта
python kontur_v18.py --cli --template Школа --save school.kontur

# Загрузка проекта
python kontur_v18.py --load school.kontur

# Импорт DXF (нужен ezdxf)
python kontur_v18.py --import plan.dxf --export

# С уличной температурой для теплопотерь
python kontur_v18.py --cli --template Офис --outdoor -35

# Тесты
python kontur_v18.py --test
```

## Tier-уровни

| Tier | ИБП | Охлаждение | Применение |
|------|-----|-----------|-----------|
| I | нет | базовое | Офисы, магазины |
| II | N+1 | усиленное | Серверные малого бизнеса |
| III | 2N | прецизионное | ЦОД, критическая инфраструктура |

## Нормативная база

- ПУЭ 7-е издание — сечения кабелей, токи, автоматы
- СП 256.1325800.2016 — электроустановки зданий
- СП 52.13330.2016 — естественное и искусственное освещение
- ГОСТ 28249-93 — расчёт токов КЗ
- СО 153-34.21.122-2003 — молниезащита
- ГОСТ 21.613-2014 — кабельный журнал
- ГОСТ 21.110-2013 — спецификация оборудования
- ГОСТ 2.710-81 — позиционные обозначения
- СП 50.13330.2012 — теплозащита зданий
- СНиП 23-03-2003 — защита от шума

## 7 новых подсистем v18

1. **ProjectManager** — `.kontur` (JSON) с автосохранением и миграцией схем
2. **DXFImporter** — импорт LINE→стены, INSERT→устройства, TEXT→аннотации
3. **ScaleManager** — 50 px/м, пересчёт длин кабеля и площадей
4. **ZCoordinator** — Device.z (высота) + вертикальная длина кабеля
5. **ExternalCatalog** — `catalog.json` с импортом прайс-листов CSV
6. **MultiProjectManager** — несколько проектов, сравнение по метрикам
7. **HeatLoss + Acoustic** — теплопотери по СП 50.13330, шум по СНиП 23-03
